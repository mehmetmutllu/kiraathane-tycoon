8Satın almalar için hizmet hesabı (RevenueCat bağlantısı)

Oyun satın almaları RevenueCat adlı bir hizmetle yönetiyor. RevenueCat'in Google Play'deki satın almaları doğrulayabilmesi için bir hizmet hesabı (robot kullanıcı) ve onun anahtar dosyası (JSON) gerekiyor. 10 dakikalık iş:

8.1 Google Cloud'da hizmet hesabı oluştur

  1. https://console.cloud.google.com adresine Play Console'a girdiğin aynı Google hesabıyla gir.
  2. Üstteki proje seçiciden New project → ad: tea-house-play → Create. Projenin seçili olduğundan emin ol.
  3. Arama kutusuna Google Play Android Developer API yaz → aç → Enable.
  4. Aynı şekilde Google Play Developer Reporting API → Enable.
  5. Sol menü IAM & Admin → Service Accounts → Create service account → ad: revenuecat → Create and continue.
  6. Roller (Grant access): Pub/Sub Admin ve Monitoring Viewer ekle → Continue → Done.
  7. Listede oluşan hesaba tıkla → Keys sekmesi → Add key → Create new key → JSON → Create. Bilgisayarına bir .json dosyası iner. Bu dosyayı sakla.
  8. Hesabın e-posta adresini kopyala (revenuecat@tea-house-play….iam.gserviceaccount.com gibi).

8.2 Hizmet hesabını Play Console'a davet et

  1. Play Console'da tüm uygulamalar ekranına dön (sol üst ok) → Users and permissions (Kullanıcılar ve izinler) → Invite new users.
  2. E-posta: 8.1'de kopyaladığın hizmet hesabı adresi.
  3. App permissions sekmesi → Add app → Tea House Tycoon → şu izinleri işaretle:
    • View app information and download bulk reports (read-only)
    • View financial data, orders, and cancellation survey responses
    • Manage orders and subscriptions
  4. Apply → Invite user → onayla.

8.3 Mehmet'e gönder

Mehmet'e gönderilecek
  • İndirdiğin .json dosyası (doğrudan, özel mesajla; herkese açık gruba veya buluta paylaşım linkiyle koyma).
  • "Ürünler etkin, hizmet hesabı davet edildi" bilgisi.
Mehmet dosyayı RevenueCat'e yükleyecek. Google'ın yeni hizmet hesabını tanıması 36 saate kadar sürebilir; bu sürede satın alma testi "geçersiz kimlik" hatası verebilir, normal.

9Yayına gönder

Adım 1'de hesabın hangi türde çıktıysa ona göre 9A veya 9B'yi uygula. Önce panodaki "Set up your app" listesinde tüm görevlerin yeşil tik aldığını kontrol et.

9A: Yeni kişisel hesap (13 Kasım 2023 sonrası): 14 günlük kapalı test

  1. Test and release → Testing → Closed testing (Kapalı test) → varsayılan "Alpha" kanalını aç → Testers sekmesi → Create email list → en az 12, tercihen 15–20 kişinin Gmail adresini ekle (birkaçı unutup çıkarsa sayı 12'nin altına düşmesin).
  2. Countries / regions: tüm ülkeler.
  3. Create new release → Adım 6'daki aynı AAB'yi seç (Add from library ile, yeniden yüklemeden) → aynı sürüm notu → Save → Send for review.
  4. Google onaylayınca (birkaç saat, bazen 1–3 gün) Testers sekmesindeki katılım bağlantısını 12+ kişiye gönder. Her biri bağlantıyı Android telefonunda açıp "Become a tester" demeli, sonra Play Store'dan oyunu kurmalı.
  5. 14 gün boyunca testçiler listeden çıkmamalı ve oyunu ara ara açmalı (Google 2026'dan beri testçilerin oyunu gerçekten kullandığına da bakıyor).
  6. 14 gün dolunca panoda "Apply for production" (Üretim erişimine başvur) etkinleşir. Formdaki sorulara dürüstçe cevap ver, örnek:
    • Testçileri nasıl buldun? "Friends and family, 15+ Android users."
    • Geri bildirim nasıl toplandı? "In person and via messaging; we fixed balance and UI issues they reported."
    • Uygulama kimin için? "Casual players 13+ who enjoy idle/tycoon games."
  7. Onay gelince (genelde ≤ 7 gün) 9B'ye geç.

9B: Üretime yayınla

  1. Test and release → Production (Üretim) → Create new release.
  2. Add from library → aynı AAB → aynı sürüm notu.
  3. İstersen staged rollout (kademeli yayın) yüzdesini %100 bırak (yeni uygulamada kademe gereksiz).
  4. Next → Save → Send for review (İncelemeye gönder). Publishing overview (Yayınlama özeti) sayfasında "Changes in review" görünür.
  5. İnceleme yeni uygulamada genelde 1–7 gün. Onaylanınca oyun otomatik yayına girer (Publishing overview'da "Managed publishing" kapalı kalsın).
Yayına çıkınca Mehmet'e haber verMehmet reklam hesabını (AdMob) mağaza sayfasına bağlayacak. Bu bağlantı reklam gelirinin tam açılması için gerekli.
